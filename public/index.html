💡 Cấu Trúc File Fanpage Karma Hỗ Trợ

Hệ thống tự động thông minh nhận diện các tiêu đề cột sau:

Tên trang Page, Fanpage, Name, Profile
Lượt xem Views, Video Views, Impressions
Tần suất bài đăng Posts per day, Posts/day, Frequency
Tổng bài đăng Number of posts, Posts, Post count
Tương tác Interactions, Reactions, Engagement
Tỷ lệ tương tác Engagement Rate, ER (%)
Followers / Fans Followers, Fans, Page Likes

Thông Tin Kết Nối Google Apps Script

Dùng để cấu hình trong file script tự động hóa trên hộp thư maiduc2311@gmail.com

Dán URL này vào mục CONFIG.CRM_WEBHOOK_URL trong Google Apps Script.

🚀 3 Bước Kích Hoạt Nhanh:

  1. Vào script.google.com với tài khoản maiduc2311@gmail.com.
  2. Tạo dự án mới và dán toàn bộ code trong file google_apps_script/fanpage_karma_sync.gs vào.
  3. Chọn hàm createDailyTrigger và nhấn Run để hẹn giờ tự động quét email mỗi ngày lúc 7h sáng.
